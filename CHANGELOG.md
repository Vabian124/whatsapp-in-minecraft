# Changelog

## 1.0.0

- Client-side Fabric mod for Minecraft 26.3, which is the main release.
- Separate jar for Minecraft 1.21.11.
- Lite mode, the default: one private WhatsApp contact, replies with a prefix, and the Minecraft server does not see that thread.
- Full mode, switched in the same screen: a hosted world shares player chat with one WhatsApp group.
- Settings open with `/whatsapp`, or from Esc, Mods, WhatsappMC when Mod Menu is installed.
- Local bridge that links one WhatsApp account and forwards only that one chat.
- Replies typed with the chosen prefix stay on this computer and are not sent to the Minecraft server.
